# Polymarket Bot

An automated trading bot for Polymarket focused on geopolitical prediction markets.

> 🚧 This project is currently under active development.

## Goals

- Retrieve live Polymarket market data
- Monitor geopolitical prediction markets
- Integrate news feeds
- Implement configurable trading strategies
- Support paper trading and live trading
- Maintain a modular and well-tested architecture

## Tech Stack

- Python
- Requests
- python-dotenv
- Rich
